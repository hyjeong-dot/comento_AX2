## 1. 목적

파일럿 50건 실행 결과, 담당자 수동 리뷰가 필요한 비율이 50%(25/50)로 나왔습니다. 이 수치가 **AI 추출 품질이나 매칭 로직의 결함이 아니라, 캠프 카탈로그(직무코드_캠프명_매핑.csv)가 커버하는 직무 범위가 실제 유저 수요보다 좁기 때문**임을 데이터로 설명합니다.

## 2. 매칭 조건 (어떤 기준으로 캠프를 연결했는가)

### ① 대상 필터링
`question_category_group == '취업 고민'`인 데이터만 슬롯필링 대상으로 삼습니다. (이직 고민·대학생 고민·랜선 사수 등은 별도 트랙)

### ② AI 슬롯필링
유저 고민 원문에서 `job_category`(직무중분류), `job_detail`(상세분류), `industry`(산업)를 추출하고, 각 값을 어떤 근거로 판단했는지(`명시`/`추론`/`없음`) 함께 기록합니다.

### ③ 4단계 폴백 매칭 (룰 기반)
추출된 3개 값으로 아래 순서대로 캠프 CSV를 조회하고, 캠프가 1개 이상 나오는 첫 단계에서 확정합니다.

| 레벨 | 검색 키 | 의미 |
|:---:|:---|:---|
| 1 | `{job_category}-{job_detail}-{industry}` | 정확매칭 |
| 2 | `{job_category}-N/A-{industry}` | 상세생략 |
| 3 | `{job_category}-{job_detail}-산업무관` | 산업확장 |
| 4 | `{job_category}` 전체 | 카테고리 폴백 |
| 0 | 위 4개 모두 실패 | 매칭 불가 |

### ④ 적합도 점수 → 담당자 리뷰 여부 결정
`매칭레벨(최대 50점) + confidence(최대 30점) + 추출근거(최대 20점)`를 합산해 0~100점을 산출합니다.

| 항목 | 배점 | 세부 기준 |
|:---|:---:|:---|
| 매칭레벨 | 50 | 1=50, 2=30, 3=15, **4=0**, **0=0** |
| confidence | 30 | `confidence × 30` |
| 추출근거 | 20 | job_category 근거(명시12/추론6/없음0) + industry 근거(명시8/추론4/없음0) |

**담당자 리뷰 조건 (아래 중 하나라도 해당하면 리뷰 큐로)**
- `confidence ≤ 0.5`
- `적합도 점수 ≤ 50`

레벨 0(매칭 실패)·4(카테고리 폴백)는 confidence와 근거가 아무리 좋아도 최대 50점(=confidence 30 + 근거 20)을 넘지 못하도록 설계되어 있어, **매칭 실패와 카테고리 전체 폴백은 다른 조건과 무관하게 항상 리뷰 대상**이 됩니다.

## 3. 파일럿 50건 실제 수치

| 레벨 | 건수 | 비율 |
|:---:|---:|---:|
| 1 (정확매칭) | 3 | 6% |
| 2 (상세생략) | 15 | 30% |
| 3 (산업확장) | 7 | 14% |
| 4 (카테고리 폴백) | 18 | 36% |
| 0 (매칭실패) | 7 | 14% |
| **담당자 리뷰 필요 합계** | **25 / 50** | **50%** |

리뷰 사유 내역: `LOW_SUITABILITY_SCORE`(레벨 0·4 대부분) 18건, `NO_CAMP_MATCH`(레벨 0) 7건.

## 4. 원인 분석: "해당 부트캠프가 없기 때문"

리뷰 필요 비율 50%의 원인을 캠프 CSV 원본 통계로 직접 확인했습니다.

### 4-1. 직무코드(정확 키) 단위가 애초에 촘촘하지 않음
- 전체 직무코드(직무-상세-산업 조합) **451개 중 316개(70%)가 캠프 1개뿐**입니다.
- 상세분류나 산업 중 하나만 어긋나도 1순위(정확매칭)가 불가능한 구조라, 레벨 2·3 비율이 44%로 높게 나타납니다.

### 4-2. 직무중분류(카테고리 폴백 풀) 자체가 얇은 경우가 많음
- 직무중분류 **145개 중 40개는 카테고리 전체를 통틀어도 캠프가 1개**뿐입니다 (예: 경영지원, 공정, 기구설계, 법무, 사회복지사 등).
- 이런 직무는 AI가 상세·산업까지 정확히 추출해도 매칭될 캠프가 CSV에 아예 존재하지 않아, 곧바로 레벨 3/4 또는 매칭 실패로 귀결됩니다.

### 4-3. 실제 유저 수요와 캠프 카탈로그 사이의 직접적인 공백
`취업 고민` 474건의 `question_target_job`(유저가 직접 입력한 목표 직무)을 캠프 CSV의 직무중분류 리스트와 대조한 결과, **48종(총 77건)의 직무가 캠프 카탈로그에 대응하는 직무중분류 자체가 없습니다.**

| 직무 | 수요 건수 | 비고 |
|:---|---:|:---|
| 총무 | 7 | 완전 미매핑 |
| 데이터분석가 | 4 | 완전 미매핑 |
| 회로설계 | 3 | job_detail 리스트에는 존재 — AI가 job_category로 착각하기 쉬운 구조 |
| 공정개발 / 생산 / 재무·자금 / 제품개발 / 물류·여객영업 | 각 3 | 완전 미매핑 |

(전체 목록은 `camp_coverage_gap_analysis.xlsx`의 `1_완전공백_직무` 시트 참고)

## 5. 결론

- **매칭 로직 자체는 설계대로 정확히 동작하고 있습니다.** 캠프가 없거나 얇은 케이스를 놓치지 않고 담당자 리뷰로 넘기는 것이 의도한 동작입니다.
- 리뷰 필요 비율 50%는 **AI 정확도 문제가 아니라 캠프 카탈로그의 직무 커버리지 문제**이며, 캠프 콘텐츠(부트캠프)를 늘리면 자연히 낮아지는 지표입니다.
- 캠프 확충 우선순위 판단은 `camp_coverage_gap_analysis.xlsx`를 참고해 부트캠프 기획 부서에서 진행하면 되고, 캠프가 추가되면 CSV만 갱신하면 파이프라인 코드 변경 없이 매칭 결과에 즉시 반영됩니다.
